# Level Up — план проекта

_Обновлено: 2026-10-10 · статус: этап 3 готов; сервер ждёт выкладки на VPS_

## 1. Проблема и цель

Цели, дневник и канбан постоянно бросаются, потому что:
- всё в разных приложениях;
- всё нужно вводить руками — долго и скучно;
- то, что держишь в голове, забывается.

**Цель:** одно iOS-приложение, куда любая мысль попадает голосом или текстом за 3–5 секунд, а ИИ сам раскладывает её по модулям, учитывает твою жизнь (график, привычки, ограничения) и превращает прогресс в «прокачку» уровня.

## 2. Принципы

1. **Одна точка ввода для всего.** ИИ сам решает: задача, трата, покупка, дневник, факт о тебе.
2. **Ничего не теряется.** Сначала сохраняется сырой текст, потом ИИ его разбирает.
3. **Никаких обязательных полей.** ИИ заполняет, ты подтверждаешь или правишь.
4. **Приложение само приходит к тебе:** утренний план, вечерний вопрос «как прошёл день?».
5. **Прогресс вместо стыда.** Опыт только растёт, пропуски не наказываются.
6. **Маленькие этапы.** Пользоваться приложением самому — как можно раньше.

## 3. Глобальные требования (касаются всех модулей)

### 3.1 Персонализация — «Обо мне»

ИИ помнит факты о тебе и учитывает их **в каждом** запросе: при планировании, напоминаниях, советах, квестах.

**Что хранится (категории):**

| Категория | Примеры |
|---|---|
| График (занятое время) | «Пт 12:30–14:00 — жума», «Работа пн–пт 9:00–18:00», «Сон 23:30–7:00» |
| Предпочтения | «Тренируюсь по утрам», «Без звонков после 21:00», «Сложные задачи — до обеда» |
| Здоровье и питание | ограничения в еде, травмы (учитываются в тренировках и покупках) |
| Финансы | день зарплаты, валюта, месячный бюджет |
| Фокус и ценности | «В этом году приоритет — здоровье и английский» |
| Личное | имя, часовой пояс, язык, рост/вес (для тренировок) |

**Как факты попадают в профиль:**
- **Из любого ввода.** «У меня в пятницу с 12:30 до 14:00 жума» → ИИ распознаёт тип `profile_fact` → карточка «Запомнить: каждую пятницу 12:30–14:00 — жума (занят)?» → ✓.
- **Вручную** в разделе «Обо мне»: список, редактирование, выключение, удаление.
- **Короткое знакомство при первом запуске:** 4–5 вопросов голосом (график работы, сон, когда тренируешься, главные цели).

**Как используются:**
- Любой вызов ИИ идёт через `ContextBuilder` (см. §6) — он добавляет в запрос блок «Обо мне». Напрямую к ИИ модули не обращаются, это правило.
- Планирование не ставит задачи на занятое время. Если ты сам просишь «созвон в пятницу в 13:00» → «⚠️ Пересекается с жума (12:30–14:00). Перенести на 14:30?».
- Пересечения проверяет не только ИИ, но и код (по структурированным данным факта), чтобы не зависеть от «внимательности» модели.
- Напоминания не приходят в занятые слоты (кроме срочных).

Пример факта:
```json
{
  "category": "schedule",
  "text": "Каждую пятницу 12:30–14:00 — жума",
  "data": { "weekday": "FRI", "start": "12:30", "end": "14:00", "repeat": "weekly", "busy": true },
  "is_active": true
}
```

### 3.2 Level Up — прокачка

Приложение должно реально поднимать твой «уровень»: игровая механика плюс видимый рост в цифрах.

**Опыт (XP) за реальные действия:**

| Действие | XP |
|---|---|
| Задача выполнена | 5–30 (по сложности; ИИ оценивает при создании) |
| Запись в дневнике | 15 (раз в день) |
| Тренировка | 25, личный рекорд +50 |
| Неделя в рамках бюджета | 50 |
| Шаг к цели | 100, цель достигнута — 500 |
| Квест выполнен | 50–200 |

**Уровни:**
- Общий уровень + полоса прогресса на главном экране. Каждый следующий уровень дороже: до уровня N+1 нужно `100 × N^1.5` XP (1→2: 100, 5→6: ~1100, 10→11: ~3200).
- **Сферы жизни** со своими уровнями (можно переименовать и добавить свои): 💪 Тело · 🧠 Разум · 💰 Финансы · ⚙️ Дисциплина · 🌿 Баланс. ИИ относит каждое действие к сфере: «прочитать главу» → Разум.
- **Квесты:** ИИ составляет задания на день или неделю по твоим целям и с учётом профиля («3 тренировки на этой неделе, ни одна не в пятницу 12:30–14:00»).
- **Достижения:** «7 дней дневника подряд», «Личный рекорд в жиме», «Месяц без перерасхода».
- **Серии без наказания:** один пропуск серию не сбрасывает («заморозка»). После перерыва — квест «Вернись», а не ноль.
- **Момент повышения уровня:** анимация, вибрация и короткое сообщение от ИИ, за что ты его получил.

**Правила честности:**
- XP начисляет код по фиксированным правилам, не ИИ. ИИ только оценивает сложность и сферу при создании записи.
- Дневной лимит XP за мелкие задачи, чтобы нельзя было «нафармить».
- Отменил выполнение — XP списывается.
- Все начисления хранятся журналом (`xp_events`), уровень считается из него.

### 3.3 Ничего не теряется

Любой ввод сначала сохраняется как `capture`. Если ИИ недоступен, нет сети или кончился лимит, запись лежит во «Входящих» и разбирается позже: автоматически или кнопкой.

### 3.4 Два языка: ru (по умолчанию) + en

- Интерфейс: String Catalog (`.xcstrings`) в iOS.
- Ввод понимается на обоих языках, в том числе вперемешку.
- ИИ отвечает на языке интерфейса.
- Язык распознавания речи (ru-RU / en-US) выбирается в настройках.

### 3.5 Голос и руки везде

Каждую запись можно создать голосом и вручную, и любую можно отредактировать вручную.

## 4. Как работает ввод

```
Голос / текст / Siri / виджет / Action Button
        ↓
Сырой текст → capture («Входящие»), сохранён сразу
        ↓
Сервер: ContextBuilder (дата, «Обо мне», цели, категории) + ИИ → строгий JSON
        ↓
Карточки: ✓ сохранить / ✎ поправить      (через Siri — сохраняется сразу, есть «Отменить»)
        ↓
Записи разложены по модулям, напоминания поставлены, начислен XP
```

Пример: «Завтра в 9 позвонить в банк, купить молоко и хлеб. Потратил 3500 на такси. Сегодня жал 80 кг, 3 подхода по 5»

```json
{ "items": [
  { "type": "task", "title": "Позвонить в банк", "due_at": "2026-10-10T09:00", "remind": true, "difficulty": 1, "sphere": "Дисциплина" },
  { "type": "shopping", "items": [{ "name": "Молоко" }, { "name": "Хлеб" }] },
  { "type": "expense", "amount": 3500, "category": "Транспорт", "note": "Такси" },
  { "type": "workout", "exercise": "Жим лёжа", "sets": 3, "reps": 5, "weight_kg": 80 }
]}
```

Типы, которые распознаёт ИИ: `task`, `reminder`, `journal`, `goal`, `shopping`, `expense`, `income`, `workout`, `profile_fact`, `question` (вопрос к своим данным).

## 5. Модули

| Модуль | Что умеет | Пример голосом |
|---|---|---|
| Задачи + канбан | список и доска (Сделать / В работе / Готово), перетаскивание, приоритет, срок, подзадачи, связь с целью, сложность и сфера для XP | «Завтра до обеда отправить отчёт, срочно» |
| Напоминания | время, повторы, локальные уведомления; занятые слоты из профиля учитываются | «Каждый понедельник в 9 напоминай про планёрку» |
| Дневник | записи по дням, настроение и энергия, теги, резюме от ИИ, лента и календарь | «День тяжёлый, но тренировкой доволен» |
| Цели | цель → шаги → задачи, метрика прогресса, дедлайн, ИИ разбивает на шаги с учётом графика | «К декабрю хочу пробежать 10 км» |
| Покупки | списки, количество, «купил» одним тапом | «Купить молоко, 2 хлеба и корм коту» |
| Финансы | доходы и расходы, категории, валюта, график за месяц, бюджет по категориям | «Получил зарплату 450 000» |
| Тренировки | тренировка → упражнения → подходы (вес × повторы, время, дистанция), график прогресса, личные рекорды | «Присед 3 по 8 с 80, потом планка 2 минуты» |
| Обо мне | факты профиля (§3.1) | «Я не ем после 20:00» |
| Прогресс | уровень, сферы, квесты, достижения (§3.2) | — |
| Входящие | неразобранный ввод, «разобрать снова» | — |
| Советы от ИИ | утренний план, вечерний вопрос, обзор недели, вопросы к своим данным | «Сколько я потратил на кафе в сентябре?» |

Вкладки: **Сегодня** (уровень, задачи, напоминания, квесты, кнопка микрофона) · **Задачи** · **Дневник** · **Прогресс** · **Ещё** (цели, покупки, финансы, тренировки, обо мне, входящие, настройки).

## 6. ИИ-слой (на сервере)

**Почему ИИ теперь на сервере, а не на телефоне:**
- бэкенд на Python, а там удобнее всего работать с ИИ;
- агенту нужен контекст из базы: профиль, цели, история;
- промпты можно менять без переустановки приложения;
- фоновые задачи (обзор недели) можно выполнять на сервере.

**Свой ключ (BYOK):**
- В настройках приложения: провайдер (OpenAI / Gemini), ключ, модель, кнопка «Проверить».
- Ключ один раз уходит на сервер по HTTPS, хранится **зашифрованным** (AES-GCM, мастер-ключ в переменной окружения) и обратно не отдаётся. В приложении виден только как `sk-…abcd`. Удалить можно в любой момент.
- Gemini — по умолчанию (есть бесплатный тариф, модели Flash, с лимитами). OpenAI — платно, для тестов.
- ⚠️ На бесплатном тарифе Gemini Google может использовать запросы для обучения моделей — важно для дневника.

**Устройство:**
- `AIProvider` (интерфейс) → `OpenAIProvider`, `GeminiProvider`. Новый провайдер = один новый файл.
- Схемы ответов описаны один раз в Pydantic. Оба провайдера отвечают строго по JSON-схеме (structured output).
- `ContextBuilder` собирает для каждого запроса:
  - текущую дату, день недели, время, часовой пояс, язык;
  - активные факты «Обо мне»;
  - контекст модуля: категории, активные цели, списки покупок, сферы.
- **Экономия токенов:** для советов отправляем сводные цифры, а не все записи. На вопрос «сколько на кафе?» ИИ возвращает фильтр, а считает база.

**Распознавание речи** — Apple Speech на телефоне: бесплатно, текст виден во время речи. На сервер уходит только текст.

## 7. Быстрый ввод и виджеты

### 7.1 Siri и Action Button

- **Siri не понимает русский** (и казахский), поэтому голос распознаёт само приложение (Apple Speech):
  - **«Записать»** — команда открывает Level Up и сразу начинает слушать. Её запускают Siri («Record in Level Up», если Siri на английском), касание сзади, Пункт управления и виджеты.
  - **«Добавить текстом»** — без открытия приложения: текст из Команд или Siri сохраняется сразу, без карточек. Ответ: «Готово. Задач: 1 · Покупок: 2». Окно с вопросом iOS показывает на языке Siri.
  - **«Отменить запись»** — убирает всё, что создала последняя такая запись.
- **Action Button** (iPhone 15 Pro и новее) → кнопка «Записать» из Пункта управления (§7.2).
- **Касание сзади** — для iPhone без Action Button (сейчас у тебя iPhone 12): Настройки → Универсальный доступ → Касание → Касание сзади → двойное касание → «Записать» (Level Up).
- На iPhone 12 нет Dynamic Island: Live Activity тренировки будет только на экране блокировки.
- Если сервер или ИИ недоступен → «Сохранил во входящие, разберу позже».

### 7.2 Виджеты

Цель: видеть главное и делать простые действия **не открывая приложение** — отметить задачу, вычеркнуть покупку, начать запись.

**Главный экран (и режим StandBy):**

| Виджет | Размер | Что показывает | Действие прямо в виджете |
|---|---|---|---|
| 🎤 Быстрый ввод | S, M | кнопка микрофона; M — 4 кнопки: голос, текст, трата, дневник | открыть запись сразу в нужном режиме |
| 📅 Сегодня | M, L | ближайшие задачи и напоминания; L — лента дня с занятыми слотами из «Обо мне» (например, 12:30–14:00 жума) | ✓ отметить задачу (+XP) |
| ⭐ Уровень | S, M | кольцо уровня и XP; M — сферы и XP за сегодня | — |
| 🎯 Квесты | S, M | активные квесты с прогрессом («2/3 тренировок») | — |
| 🛒 Покупки | M, L | выбранный список | ✓ вычеркнуть купленное |
| 💰 Финансы | S, M | потрачено сегодня и за месяц, остаток бюджета | ＋ трата голосом |
| 🏋️ Тренировки | S, M | последняя тренировка, сколько за неделю, свежий рекорд | начать тренировку |
| 🏁 Цель | S | прогресс выбранной цели, сколько дней осталось | — |
| 📓 Дневник | S | серия дней; вечером — «Как прошёл день?» | записать день голосом |

S / M / L — маленький, средний, большой.

**Экран блокировки:**
- круглые: 🎤 быстрый ввод, кольцо уровня, прогресс цели;
- прямоугольный: следующая задача со временем или остаток бюджета на сегодня;
- строка над часами: «Ур. 7 · 3 задачи».

**Пункт управления:** кнопки «🎤 Записать», «💸 Трата», «📓 Дневник». Любую из них можно назначить на Action Button.

**Live Activity:** во время тренировки на экране блокировки и в Dynamic Island видны текущее упражнение и таймер отдыха.

**Общие правила:**
- **Настраиваются:** в виджете «Цель» выбираешь цель, в «Покупках» — список, в «Уровне» — сферу.
- **Умный стек:** виджет подсказывает iOS, когда он важнее: утром «Сегодня», вечером «Дневник».
- **Учитывают «Обо мне»:** занятые слоты видны, задачи на это время не предлагаются.
- **Оформление:** светлая, тёмная и тонированная темы; ru и en.
- **Обновление:** сразу после изменений в приложении, а по расписанию — в полночь и ко времени напоминаний.
- **Правило:** каждый новый модуль получает свой виджет.

**Как устроено:**
- Общий Swift-пакет `LevelUpKit` (модели, API-клиент, снимок данных). Его используют приложение, виджеты и Siri.
- После каждого изменения приложение записывает компактный снимок `WidgetSnapshot` в общее хранилище App Group и просит iOS обновить виджеты. В снимке: задачи на сегодня, списки, уровень, квесты, бюджет, цели.
- Кнопки в виджетах (iOS 17+) — это App Intents. Они сразу меняют снимок и отправляют изменение на сервер; без сети изменение ждёт в очереди.
- Если App Group недоступна на бесплатном Personal Team, есть запасной вариант: виджет сам запрашивает `GET /widgets/snapshot` с токеном из общего Keychain. Это проверим на этапе 0.

## 8. Вход и сессия

- **Google** — в первой версии. Приложение получает Google ID token, сервер проверяет его и выдаёт свои токены.
- **Без регистрации** — в первой версии: аккаунт привязан к устройству, Google можно привязать потом, данные сохранятся.
- **Sign in with Apple** — когда появится личный платный аккаунт разработчика (см. §14).
- **Телефон + SMS** — позже, нужен платный SMS-провайдер.
- **Долгая сессия:** access JWT живёт 1 час, refresh token — 180 дней со скользящим продлением. Каждое обновление снова даёт 180 дней, старый refresh токен при этом аннулируется. Итог: если открываешь приложение хотя бы раз в полгода, разлогинивать не будет никогда. Токены хранятся в Keychain.

## 9. Стек

**iOS:**
- Swift 6, SwiftUI, iOS 18+
- MVVM на `@Observable`, код разбит по модулям
- Локальная копия: на этапе 1 — JSON-кэш и очередь неотправленных записей; SwiftData — когда понадобится полная офлайн-синхронизация
- App Intents — Siri, Action Button, кнопки в виджетах
- WidgetKit — виджеты главного экрана, экрана блокировки, StandBy и Пункта управления
- ActivityKit — Live Activity во время тренировки
- `LevelUpKit` — общий Swift-пакет для приложения, виджетов и Siri
- Speech — распознавание речи
- UserNotifications — локальные напоминания
- Swift Charts — графики
- Keychain — токены
- GoogleSignIn-iOS — вход через Google
- Сеть: `URLSession` + async/await

**Бэкенд:**
- Python 3.12+, FastAPI, Pydantic v2
- SQLAlchemy 2.0 (async) + asyncpg, миграции Alembic
- PostgreSQL 16+
- Авторизация: `google-auth` (проверка Google ID token) + свои JWT (PyJWT); refresh-токены хранятся в базе в виде хэша
- ИИ: официальные SDK `openai` и `google-genai`
- Шифрование ключей: `cryptography` (AES-GCM)
- Инструменты: `uv` (зависимости), `ruff` (линтер), `pytest` (тесты)
- Фоновые задачи (обзор недели) — позже

**Разработка и деплой:**
- Локально: Docker Compose (api + postgres).
- iPhone подключается к серверу на Mac по локальной сети или через туннель (cloudflared).
- Хостинг: VPS (~$5/мес, Ubuntu 24.04) — Docker Compose + Caddy с HTTPS и ежедневный дамп базы. Всё лежит в `deploy/`, выкладка — `make deploy`. Render + Neon отклонили: бесплатный сервер засыпает, и первый запрос ждёт до минуты.

## 10. Архитектура

```
iPhone (SwiftUI)
 ├─ Ввод: текст · голос (Apple Speech) · Siri · виджет · Action Button
 ├─ SwiftData — локальная копия + очередь изменений без сети
 ├─ Виджеты + Live Activity ← снимок данных в App Group (LevelUpKit)
 ├─ Локальные уведомления (напоминания)
 └─ HTTPS + JWT ─────────────▶ Backend (FastAPI, Python)
                                ├─ Auth: Google · без регистрации · (позже Apple, телефон)
                                ├─ Captures → ContextBuilder → AIProvider ──▶ OpenAI / Gemini
                                ├─ Модули: задачи, дневник, цели, покупки, финансы, тренировки
                                ├─ Профиль «Обо мне» · XP / уровни / квесты
                                └─ PostgreSQL
```

**Синхронизация:**
- Сервер — источник истины.
- Телефон хранит копию и показывает её мгновенно.
- Изменения без сети копятся в очереди и отправляются, когда сеть появится.
- При конфликте побеждает последнее изменение (`updated_at`).
- Удаления мягкие (`deleted_at`).

## 14. Аккаунт разработчика Apple

- **Аккаунт компании не используем.** Всё, что в нём создаётся (App ID, устройства, сборки TestFlight), видят как минимум админы команды, а приложение юридически принадлежит компании. Скрыть это нельзя.
- **Сейчас — бесплатный Personal Team:** Xcode → Signing → Team = «<твоё имя> (Personal Team)». Компания его не видит. Для надёжности можно добавить в Xcode отдельный личный Apple ID.
- **Ограничения бесплатного варианта:**
  - сборка на iPhone работает 7 дней, потом переустановка из Xcode (около минуты);
  - нет Sign in with Apple, push-уведомлений с сервера и TestFlight;
  - локальные напоминания, Siri (App Intents) и распознавание речи работают;
  - ✅ общее хранилище App Group для виджетов работает: Personal Team выдаёт профиль с `group.com.zharylkasynov.levelup` (проверено на этапе 0).
- **Когда приложение «приживётся»:** личный Apple Developer ($99/год). Даст сборки TestFlight на 90 дней, Sign in with Apple и push.

| Вопрос | Решение |
|---|---|
| Платформа | только iOS, Swift / SwiftUI |
| Бэкенд | Python (FastAPI) + PostgreSQL |
| ИИ | на сервере, ключ пользователя (BYOK) в зашифрованном виде; OpenAI + Gemini, по умолчанию Gemini |

| Персонализация | глобальное требование: все вызовы ИИ идут через `ContextBuilder` с «Обо мне» |
| Прокачка | XP и уровни считает код по правилам; ИИ только оценивает сложность и сферу |
