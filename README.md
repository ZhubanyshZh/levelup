# Level Up

Одно iOS-приложение для задач, дневника, целей, покупок, финансов и тренировок: ввод голосом или текстом, ИИ раскладывает всё по местам, а прогресс превращается в уровень.

Полный план — [docs/PLAN.md](docs/PLAN.md).

## Структура

```
backend/     FastAPI + PostgreSQL (Python 3.13, uv, SQLAlchemy, Alembic)
ios/         SwiftUI-приложение; Xcode-проект генерируется XcodeGen из ios/project.yml
  LevelUp/         приложение
  LevelUpWidgets/  виджеты
  LevelUpKit/      общий Swift-пакет: API-клиент, модели, токены, данные для виджетов
deploy/      сервер на VPS: Docker Compose + Caddy, скрипты выкладки
docs/        план и решения
```

## Что нужно на Mac

Xcode 26+, Docker, [uv](https://docs.astral.sh/uv/) и [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
brew install uv xcodegen
```

## Запуск

1. База и сервер в Docker:

   ```bash
   cp backend/.env.example backend/.env   # только при первом запуске; заполнить секреты
   make docker
   ```

   Проверка: http://localhost:8000/health, документация API: http://localhost:8000/docs. `make docker` собирает API, запускает оба контейнера в фоне, применяет миграции и ждёт готовности API и базы. База использует постоянный том `levelup_db-data`.

   `make docker-logs` показывает запросы к API; `make docker-stop` останавливает контейнеры с сохранением данных. После изменения бэкенда снова выполни `make docker`.

   Для запуска API вне Docker: `make db`, `make migrate`, `make api` (сначала остановить контейнер API: `docker compose stop api`).

2. Приложение:

   ```bash
   cp ios/Config/Local.example.xcconfig ios/Config/Local.xcconfig   # и заполнить
   make ios-open
   ```

   В Xcode выбрать симулятор или iPhone и нажать Run.

## Запуск на iPhone

- В `ios/Config/Local.xcconfig`:
  - `DEVELOPMENT_TEAM` — **личный Personal Team**, не командный аккаунт компании;
  - `API_BASE_URL` — IP Mac в той же Wi-Fi сети, например `http:/$()/192.168.0.54:8000`. IP можно узнать командой `ipconfig getifaddr en0`.
- Если IP Mac изменится, обнови `API_BASE_URL` и точечное HTTP-разрешение `NSExceptionDomains` в `ios/project.yml` (у приложения и виджетов). После правок в `Local.xcconfig` или `project.yml` снова выполни `make ios`.
- Mac и iPhone должны быть в одной локальной сети. Открой в Safari на телефоне `http://<IP Mac>:8000/health`: ожидается `status: ok` и `database: ok`. Телефон обращается к контейнеру API через порт 8000 Mac; API подключается к базе внутри Compose по `db:5432`.
- При первом запуске на iPhone:
  - разрешить доступ к локальной сети;
  - если iOS попросит, довериться разработчику: Настройки → Основные → VPN и управление устройством.
- Сборка на бесплатном Personal Team работает 7 дней. Потом снова Run из Xcode.

## Сервер в интернете

Чтобы приложение работало не только в домашнем Wi-Fi, сервер живёт на VPS. В `deploy/` лежат Postgres, API и Caddy: Caddy сам получает HTTPS-сертификат. Раз в сутки делается дамп базы, дампы хранятся 14 дней.

1. Купить VPS с **Ubuntu 24.04** (например, Hetzner CX22, ~€4/мес). При создании добавить свой SSH-ключ (`cat ~/.ssh/id_ed25519.pub`).
2. Создать секреты сервера. Домен получится вида `1-2-3-4.sslip.io` (бесплатный, указывает на IP сервера):

   ```bash
   make server-env IP=<IP сервера>
   ```

   Сохрани `deploy/.env` в менеджере паролей. Без `ENCRYPTION_KEY` ключи ИИ не расшифровать.
3. Подготовить сервер (один раз): Docker, файрвол, автообновления.

   ```bash
   make server-setup HOST=root@<IP сервера>
   ```

4. Выложить. Эту же команду повторять после каждого изменения бэкенда:

   ```bash
   make deploy HOST=root@<IP сервера>
   ```

5. В `ios/Config/Local.xcconfig`: `API_BASE_URL = https:/$()/<домен из deploy/.env>`. Затем `make ios` и Run.

На сервере начинается чистая база: войти заново и снова ввести ключ ИИ.

Полезное:
- `make server-logs HOST=…` — логи API;
- `make server-backup HOST=…` — скачать дампы в `backups/`.

## Вход через Google

1. Открыть [Google Cloud Console](https://console.cloud.google.com/) и создать проект «Level Up».
2. **Google Auth Platform → Audience:** тип External. Добавить свой email в Test users (или опубликовать приложение — для базовых прав входа проверка Google не нужна).
3. **Clients → Create client → iOS**, Bundle ID: значение `BUNDLE_ID_PREFIX` из `Local.xcconfig` + `.levelup` (сейчас `com.zharylkasynov.levelup`).
4. Скопировать значения из созданного клиента:
   - **Client ID** → `GOOGLE_CLIENT_ID` в `ios/Config/Local.xcconfig` и `GOOGLE_CLIENT_IDS` в `backend/.env`;
   - **iOS URL scheme** → `GOOGLE_REVERSED_CLIENT_ID` в `ios/Config/Local.xcconfig`.
5. Перезапустить сервер и выполнить `make ios`.

## ИИ-помощник

Каждый пользователь подключает свой ключ: «Ещё → ИИ-помощник».

- **Gemini (бесплатно):** [Google AI Studio](https://aistudio.google.com/apikey) → Create API key.
- **OpenAI (платно):** [platform.openai.com/api-keys](https://platform.openai.com/api-keys).

Ключ уходит на сервер один раз и хранится зашифрованным (`ENCRYPTION_KEY` в `backend/.env`). Если потерять `ENCRYPTION_KEY`, ключи придётся ввести заново.

## Быстрый ввод и виджеты

- **Касание сзади** (iPhone без Action Button): Настройки → Универсальный доступ → Касание → Касание сзади → Двойное касание → «Записать». Приложение откроется и сразу начнёт слушать.
- **Пункт управления:** «+» → «Добавить элемент управления» → Level Up → «Записать», «Трата», «Дневник» или «Тренировка». На iPhone 15 Pro и новее эти же кнопки ставятся на Action Button.
- **Команды:** «Записать», «Добавить текстом» (без открытия приложения), «Трата», «Тренировка», «Дневник», «Отменить запись». Их видно в Spotlight и в приложении «Команды».
- **Siri** русский не понимает. Если Siri на английском — «Record in Level Up» откроет запись, а голос распознает уже приложение.
- **Виджеты:** «Быстрый ввод», «Сегодня», «Уровень», «Квесты», «Цель», «Финансы», «Тренировки», «Покупки», «Дневник». Плюс на экране блокировки: кнопка записи, кольцо уровня, прогресс цели, ближайшая задача. ✓ в «Сегодня» и «Покупках» работает без открытия приложения. В «Цели» и «Покупках» долгим нажатием → «Изменить виджет» выбираются цель и список.
- **Тренировка** видна на экране блокировки (Live Activity): упражнение и таймер отдыха. В первый раз iOS спросит разрешение.

Команды появляются после первого запуска приложения.

## Сессия и токены

- Access JWT живёт 1 час.
- Refresh-токен живёт 180 дней и при каждом обновлении продлевается. Если приложение открывали хотя бы раз в полгода, сессия не кончается.
- Refresh-токены одноразовые. Повторное использование старого токена отзывает весь вход. Исключение — 60 секунд на повтор запроса, если ответ потерялся в сети.
- Без сети приложение не разлогинивает: показывает профиль из кэша.


### ИИ-коуч

«Сегодня → ИИ-коуч» или «Ещё → ИИ-коуч»: утренний план, вечерний вопрос и обзор недели. В карточке цели — «Разбить цель с ИИ». Для работы нужен ключ в настройках ИИ. Предложения добавляются кнопкой принятия; при занятом или прошедшем времени выбери «Добавить без времени».

Коуч отвечает на вопросы о расходах/доходах, тренировках, днях дневника, задачах с начисленным XP и общем XP. Числа считает сервер по записанным данным. Голосовой ввод есть на экране вопроса; отложенные вопросы также открываются из «Входящих». История и черновик доступны без связи.

Автоподготовка при открытии приложения и локальные напоминания включаются отдельно в «Ритм» (изначально выключены). Напоминания планируются на 7 дней, обходят занятость из «Обо мне» и обновляются при открытии приложения. Платные вызовы ИИ выполняются при подготовке плана или ответе на вопрос; готовые планы сохраняются. Серверная генерация в фоне и push не используются.

### Серверные выборки задач

Приложение использует `GET /tasks/page` с фильтрами `due`, `priority`, `sphere`, `goal_id`, поиском `q` и параметрами `limit`/`cursor`. Страница по умолчанию содержит до 50 задач, максимум — 100. Ответ: `items` и `next_cursor`; `null` означает конец выборки. Подсчёт всей таблицы для отображения количества задач не выполняется.

Каждая колонка канбана запрашивается отдельно с `status` и `sort=position`. Для списка используется `sort=due`, активные задачи идут перед завершёнными. Отдельные серверные выборки `view=today`, `view=widgets` и `view=reminders` не зависят от фильтров экрана. Относительные сроки вычисляются в часовом поясе аккаунта. Устаревший `GET /tasks` оставлен для совместимости и ограничен первой страницей.

Перед обновлением iOS-клиента обновите backend и выполните `alembic upgrade head` (миграция `0006`). Она устанавливает `pg_trgm` и строит индексы задач через `CREATE INDEX CONCURRENTLY`, сохраняя возможность записи во время построения. На сервере с автоматическим запуском миграций достаточно дождаться успешного завершения миграции при развёртывании. Сохранённые фильтры приложения продолжают использоваться в серверных запросах.
